# vss_isc

This represents the ISC Firewall Settings container, which includes details about the ISC OVF appliance model, version, IP address, VSS internal ID, and virtual connector name.





## Simple Attributes
    
- `isc_ip_address` (String) The IP address of the ISC appliance.
- `isc_ovf_appliance_model` (String) The model of the ISC OVF appliance.
- `isc_ovf_appliance_version` (String) The version of the ISC OVF appliance.
- `isc_virtual_connector_name` (String) The name of the ISC virtual connector.
- `isc_vss_id` (String) The internal ID of the ISC VSS.
